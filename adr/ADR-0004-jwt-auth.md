# ADR-0004: Авторизация через JWT с Refresh Token в Cookie HttpOnly
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
Обеспечивает безопасность хранения токенов и защиту от XSS/CSRF атак.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
