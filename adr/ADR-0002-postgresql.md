# ADR-0002: PostgreSQL как основная СУБД, H2 только для тестов
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
PostgreSQL 16 обеспечивает транзакционную надёжность Repeatable Read и поддержку сложных запросов.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
