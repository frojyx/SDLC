# ADR-0001: Модульный монолит на Java вместо набора микросервисов
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
Для MVP SportSpot на одном сервере модульный монолит обеспечивает низкую сложность и минимальные затраты (REQ-COST-001).

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
