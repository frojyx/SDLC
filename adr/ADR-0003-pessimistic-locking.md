# ADR-0003: Пессимистическая блокировка слотов SELECT ... FOR UPDATE
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
Исключает риск физического овербукинга при одновременном бронировании слота несколькими клиентами.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
