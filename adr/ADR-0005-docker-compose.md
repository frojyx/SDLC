# ADR-0005: Развёртывание сервисов через Docker Compose
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
Позволяет воспроизводимо развернуть веб-сервис и PostgreSQL на одном VPS сервере.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
