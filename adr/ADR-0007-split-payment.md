# ADR-0007: Совместная сплит-оплата с холдированием слота в PostgreSQL
**Статус:** Принято  
**Дата:** 2026-11-23  

## Контекст
Реализация долевых платежей прямо в монолите через вебхуки эквайринга без необходимости отдельной внешней очереди.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
