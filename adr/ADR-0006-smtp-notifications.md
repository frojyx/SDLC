# ADR-0006: Асинхронная отправка email-уведомлений через SMTP
**Статус:** Предложено  
**Дата:** 2026-11-23  

## Контекст
Отправка писем выполняется вне основного пользовательского HTTP-запроса через Spring Events.

## Решение
Принято решение реализовать компонент в соответствии со спецификацией SportSpot.

## Последствия
Положительные: надёжность, простота сопровождения, соответствие срокам и бюджету.
